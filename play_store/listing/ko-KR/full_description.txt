칠흑 같은 배경 위에 입자 물리로 떨어지는 모래시계 한 개. 그뿐입니다.

광고도, 네트워크도, 분석 코드도 없습니다. 권한은 진동(VIBRATE) 하나.

■ 주요 기능

• 입자 물리 모래시계 — 모래 한 알 한 알이 독립된 입자로 떨어지고 서로 부딪히며 화면 아래에 쌓입니다. 타이머가 끝날 때까지 모래는 화면의 절반 높이를 향해 천천히 자랍니다.

• 기기 기울임 인식 — 가속도계가 실시간 중력 벡터를 넘겨받아 기기를 기울이면 모래더미가 낮은 쪽으로 쏠립니다. 평평한 책상 위, 손에 든 채로, 어떤 각도에서도 자연스럽게 반응합니다.

• 꾹 누르면 정확한 시간 — 모래만 보고 싶을 때는 그대로 두고, 정확한 남은 시간이 궁금할 때 화면을 누르고 있으면 HH : MM : SS가 부드럽게 떠오릅니다. 손을 떼면 다시 사라집니다.

• 빠른 프리셋 — 1m / 3m / 5m / 10m / 25m / 1h 칩을 한 번 탭하면 시·분·초가 채워집니다. 자주 쓰는 타이머는 두 번 탭으로 시작.

• 일시정지 / 재개 — 모래가 떨어지는 도중에 멈췄다가 그 시점부터 다시 카운트다운할 수 있습니다. 일시정지 화면에서는 남은 시간과 남은 비율(%)을 함께 보여줍니다.

• 마지막 시간 기억 — 직전에 시작했던 시·분·초가 다음 실행 때 자동으로 채워져 있어, 같은 타이머를 다시 돌릴 때는 한 번의 탭으로 충분합니다.

• 부드러운 완료음 — 모래시계가 끝나면 세 음짜리 톤이 진동과 함께 울립니다. 알림 스트림을 사용해 무음·방해금지(DnD) 설정을 그대로 따릅니다.

• 타이머 동안 화면 켜짐 — 실행 중에만 화면을 켠 상태로 유지하고, 일시정지·완료·리셋되는 즉시 해제됩니다.

■ 사용하기 좋은 순간

• 명상 / 호흡 — 알람 화면 대신 모래만 떨어지는 풍경을 마주합니다.
• 공부·작업 포모도로 — 25분 칩을 두 번 탭하면 시작.
• 잠자리 옆 5분 / 10분 차 우림 / 운동 휴식 — 산만한 디지털 인터페이스 없이 시각만으로 시간 인지.

■ 권한 / 프라이버시

• 인터넷 권한 없음. 어떤 서버와도 통신하지 않습니다.
• 광고 SDK·분석 SDK·크래시 리포트 SDK 없음.
• 위치·카메라·마이크·저장소 권한 요청 없음.
• 진동(VIBRATE) 하나만 사용하며, 완료 시 짧은 펄스에만 쓰입니다.

■ 호환성

• Android 7.0 (API 24) 이상.
• 가속도계가 있는 기기에서 기울임 인식 동작. (대부분의 휴대전화·태블릿이 해당)
• 다크 모드 전제 디자인. 시스템 다크 모드 설정과 무관하게 항상 검정 배경입니다.
