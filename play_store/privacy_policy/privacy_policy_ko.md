# Flux Hourglass 개인정보 처리방침

최종 업데이트: 2026-05-27

Flux Hourglass(이하 "본 앱")는 사용자의 어떠한 개인정보도 수집·저장·전송·공유하지 않습니다.

## 1. 수집하는 정보

본 앱은 어떠한 형태의 사용자 데이터도 수집하지 않습니다.

- 이름·이메일·전화번호 등 개인 식별 정보 수집 없음
- 위치 정보 수집 없음
- 연락처·사진·파일 등 단말 저장소 접근 없음
- 카메라·마이크 접근 없음
- 광고 식별자(AAID)·디바이스 ID·설치 ID 수집 없음
- 사용 분석(analytics)·크래시 리포팅(crash reporting) 수집 없음
- 결제 정보 수집 없음 (본 앱은 무료이며 인앱 결제가 없습니다)

## 2. 단말 권한

본 앱이 사용하는 권한은 `VIBRATE` 하나뿐이며, 모래시계 타이머가 완료된 시점의 짧은 진동 펄스에만 사용됩니다. 어떠한 식별 정보도 이 권한으로 수집되지 않습니다.

본 앱은 `INTERNET` 권한을 요청하지 않으며, 어떠한 서버와도 통신하지 않습니다.

## 3. 단말 내부에 저장되는 설정

본 앱은 사용자 편의를 위해 **마지막으로 시작한 타이머의 시·분·초 값**만을 단말 내부의 Android `Preferences DataStore`에 저장합니다. 이 값은 다음 실행 시 픽커를 미리 채우는 용도로만 사용되며, 단말 밖으로 전송되지 않습니다. 앱을 삭제하면 함께 삭제됩니다.

## 4. 제3자 SDK

본 앱은 다음 종류의 제3자 SDK를 **사용하지 않습니다**.

- 광고 SDK
- 분석 SDK
- 크래시 리포팅 SDK
- 푸시 알림 SDK
- 인앱 결제 SDK
- 소셜 로그인 SDK

## 5. 어린이 개인정보

본 앱은 어린이를 포함한 모든 사용자에게서 개인정보를 수집하지 않습니다.
