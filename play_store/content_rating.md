# Play Console 콘텐츠 등급 설문 답변

Play Console → 정책 → 콘텐츠 등급 설문지를 채울 때 그대로 사용할 수 있는 답변 모음입니다. 본 앱은 사용자 입력이 전혀 없는 단일 화면 모래시계 타이머이므로 거의 모든 항목이 "아니요"입니다.

## 카테고리 선택

- **앱 유형**: 앱 (게임 아님)
- **카테고리**: 도구(Tools) 또는 생산성(Productivity) 중 택1
  - 권장: **도구(Tools)** — Play Store 분류에서 "타이머", "모래시계" 류는 도구로 분류되는 경우가 많고, 명상 / 포모도로 / 측정 도구 컨텍스트가 더 잘 어울립니다.
- **태그(Play Store)**: 클럭(시계), 타이머, 명상, 집중

Play Console → 앱 콘텐츠 → 데이터 보안.

- **데이터 수집**: 없음 — "이 앱은 사용자 데이터를 수집하거나 공유하지 않습니다"
- **데이터 공유**: 없음
- **데이터 암호화 (전송 중)**: 해당 없음 (네트워크 통신 없음)
- **사용자 데이터 삭제 요청**: 해당 없음
- **데이터 보안 관행 자체 검증**:
  - 사용자 데이터가 전송되지 않음을 자체 검증함 ✓
