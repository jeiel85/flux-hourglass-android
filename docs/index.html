Made to be touched.만지면 반응합니다.

Hold
Press anywhere to see exactly how long is left. Let go, and it’s only sand again.
화면을 누르고 있으면 정확한 남은 시간이 떠오릅니다. 손을 떼면 다시 모래만 남아요.
Tilt
The pile follows real gravity from the accelerometer. On a keyboard, lean it with ← →.
가속도 센서의 실제 중력을 따라 더미가 쏠립니다. 키보드에서는 ← → 로 기울여요.
Draw
Drag across the stream to sketch a wall. Grains bounce off it, then it fades away.
줄기를 가로질러 그으면 벽이 생깁니다. 모래알이 튕겨 나가고, 벽은 서서히 사라져요.
Glance
In a browser tab, the icon fills with sand and the title counts down.
브라우저 탭에서는 아이콘에 모래가 차오르고, 탭 제목이 카운트다운합니다.
