# Flux Hourglass 1.0.0

Initial public release.

## Highlights

- **Particle physics hourglass.** Each grain is an independent particle that
  falls from the top, collides with the growing sand pile, and is then absorbed
  into a column whose height grows toward 50% of the screen as the timer ends.
- **Device-tilt aware.** The accelerometer feeds an `(x, y)` gravity vector
  into the slumping pass, so tipping the phone left/right makes the pile pour
  toward the lower edge — visibly, without disturbing the elapsed time.
- **Touch-to-reveal time.** Press anywhere on the running screen to fade in
  exact remaining `HH : MM : SS`; release to return to pure sand.
- **Zero side channels.** No network, no analytics, no ads, no permissions
  beyond `VIBRATE` for the completion pulse.
